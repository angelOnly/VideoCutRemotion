# 基础事实与边界

本合同仅用于 textvideo-studio 的模板动画任务。身份为 taskId、runId、stage、输入摘要、模板版本与摘要、工程和作业 ID；不建立旧平台对象。读取本 run 的输入与结果协议，核对 read_runtime_release、read_production_task 的真实返回。

Analysis 只处理完整文字、需求、模板文字约束和结果协议。Render 以本次确认全文、顺序、分镜 ID、音色要求及固定模板为准。确认正文不擅自增删；句段、分镜、章节与计算分块分别建模。

正式写入、生成和渲染由主任务协调；先保存原始返回并检查 isError，再处理结构化结果。未知结果沿原作业和幂等键核查，不换键重放。不得直接改数据库或发布目录。

源码摘要、静帧观察、连续视频观察、听审、技术生成与用户定稿分别记录；系统没有连续看听能力时只记录未观察范围，不增加 Worker 待审状态或阻止技术合格文件回传。只支持模板 Remotion 动画，超范围需求说明范围，不自动切换其他工作流。
