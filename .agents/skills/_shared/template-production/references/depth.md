# 图形层级、路径与阅读保护

仅在复杂遮挡、前后景、图形角色或安全区问题出现时读取。先确定当前第一关注、第二关注与保持稳定层，再排背景、主对象、前景强调、固定包装和普通字幕；层级是表达关系，不是无限增加 z-index。

面积、对比、速度、位置和清晰度共同决定视觉重量。一个小但高速闪烁的标签也会抢主对象；核心图形应在目标观看尺寸正常速度下自然可辨，不能只在放大截图中读出。需要共同比较的对象用对齐、接近和一致色彩语义保持关系，空白不应把它们割裂。

为入口、危险中途、主要阅读和退出分别检查实际可见区域。对象移入字幕区、缩放时超边界或连线穿过文字，要修改路径、面积或显露时机；不能仅检查静止终帧。遮挡底层若继续运动，关键关系须在真正露出时可见，不把被完全挡住的动作计作已展示。

标签随对象正确变换，普通字幕固定在最终画布；重要证据或图表读不清时调整主画面比例和阅读次序，不能把两层文字塞同一狭窄区域。安全区来自本片实际包装和交付画幅，不人为永久空出无用区域。

材质、阴影与投影共同确认接触和前后关系。快速变化可临时降低次要细节，但阅读时回到可辨状态。若需多画幅，分别安排主体、字幅、路径和负空间，不能机械中心裁切或把整幅缩小。

交回层级、占位、路径、遮挡关系、风险帧与已观察范围。当前模板无法表达关键层次时给出具体替代与表达代价；不扩展人物生成、抠像或不存在的跟踪能力。
