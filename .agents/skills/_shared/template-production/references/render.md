# Render 协调与提交

确认本次完整稿与固定模板。导演负责信息发展和采用，视觉负责美术与实现，声音负责旁白与字幕；按输入依赖真实分派或续接，不默认另找文案和素材。公共事实已在当前角色输入中提供时不重复链回。

读取模板制作入口后，各作者只读取自己的说明及当前必要接口，不要求所有角色遍历组件源码。工具发现和服务阶段权限以当前 Run 为准。

主协调负责工具提交、原作业身份和结果接回，独立查询可并行。工程结束写入后用 prepare_review_frames 一次提交本轮静帧决定；程序冻结、绘图并登记。已有媒体用 prepare_review；freezeState=waiting 时不能修改待冻结工程，frozen 后可继续下一版。服务处理排队和确定性等待。正式导出受理且无独立工作后按[导出合同](export.md)返回 await_runtime，Worker 等待终态，成功直接交付原清单，明确媒体失败才续接；不把结束该轮当最终交接，不进行正常进度轮询。

交接保留当前输入引用、实际变化、源码摘要、完成计数、异常和未完成项。原始音频数组、时间轴及完整工具响应保存 run 文件，只有具体问题才展开。最终音频核验与正式导出必须绑定同版源码。

## 按角色读取与续接

主协调只需运行合同、职责、当前材料引用、问题和状态；导演读取完整当前稿、采用设计、整体推进与场面方法。视觉作者新建连续场面读取完整美术、演出、时机与空间实现方法；声音/字幕作者读取当前全文、自然分段与字幕完整方法、实际音频。审片者只读本检查包、对应专业方法和真实证据，争议时补读设计依据及相邻关系。具体入口与参考由同一发行 manifest 的 roles 登记，不另建注册系统。

默认新作者以受管引用取得完整当前稿、设计、职责和必要接口，不继承整段父历史、图片与失败日志；原作者返修继续原线程。交接提供真实差异与完整稿引用，不只换版本号。返回采用结论、问题、产物引用和待办，全文保持可读。

可发现目录、实际读取正文和父历史继承分开记录。阶段发行只能证明阶段隔离；只有实际线程证据支持时才声称子线程发现隔离。宿主无法限制的条目明确记录，不能假称已净化。没有工具能力的连续看听保持未完成，不用静帧或读取请求代替实际观察。

## 四章滚动并行制作

主协调兼任整片导演，先读取完整确认稿，确定共享配色、字体、构图、人物和章节衔接，保存共享设计。按 input.chapterWork.units 分派最多四位真实章节作者，并同时分派一位统一声音作者。章节不足四个时按实际数量分派；一位完成立即续接下一个待做章节，不等待整批完成。宿主名额不足时记录实际并发，按空闲名额续接，不虚构四路执行。

每位章节作者读取完整稿与统一设计，仅修改分配的 sourceDirectory；回传组件、纯参数校验器和视觉块 JSON 的路径。视觉块保持现有模板的章节内时钟。主协调在首轮分派前保存工作单元与实际时间线章节的对应关系，不能把工作单元编号直接当作旧工程的章节编号。共享组件、视觉注册表和唯一 timeline.json 由主协调写入，声音作者只回传句段与字幕计划。禁止不同作者各自生成整片或各建一份配音。

配音与视觉设计并行。主协调通过现有配音和装配工具取得真实时长，统一更新总时间线，将实际章节范围和语义落点回传原作者校准。保留显式动作点，不按比例拉伸。作者全部停止写入后，主协调按当前章节顺序合并视觉块、注册组件与独立校验器，执行模板校验；不能用迟到的旧稿覆盖新时序。完成后释放空闲作者名额供独立审片使用。

局部返修只续接受影响章节；共享风格或跨章时序变化才扩大范围。保留未受影响章节与音频，不另建章节发布系统。最终仍冻结一份完整工程，由现有服务四路生成画面并生成一条连续音轨，按原顺序合成整片和分镜。
