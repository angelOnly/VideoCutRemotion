# Render 协调与提交

确认本次完整稿与固定模板。导演负责信息发展和采用，视觉负责美术与实现，声音负责旁白与字幕；按输入依赖真实分派或续接，不默认另找文案和素材。公共事实已在当前角色输入中提供时不重复链回。

读取模板制作入口后，各作者只读取自己的说明及当前必要接口，不要求所有角色遍历组件源码。工具发现和服务阶段权限以当前 Run 为准。

主协调负责工具提交、原作业身份和结果接回，独立查询可并行。工程结束写入后提交本轮全部静帧批次，prepare_review 等待同快照完整材料并一次创建计划；不能在尚未冻结的运行中继续修改。服务处理排队和确定性等待。正式导出受理且无独立工作后按[导出合同](export.md)返回 await_runtime，Worker 等待终态，成功直接交付原清单，明确媒体失败才续接；不把结束该轮当最终交接，不进行正常进度轮询。

交接保留当前输入引用、实际变化、源码摘要、完成计数、异常和未完成项。原始音频数组、时间轴及完整工具响应保存 run 文件，只有具体问题才展开。最终音频核验与正式导出必须绑定同版源码。

## 按角色读取与续接

主协调只需运行合同、职责、当前材料引用、问题和状态；导演读取完整当前稿、采用设计、整体推进与场面方法。视觉作者新建连续场面读取完整美术、演出、时机与空间实现方法；声音/字幕作者读取当前全文、自然分段与字幕完整方法、实际音频。审片者只读本检查包、对应专业方法和真实证据，争议时补读设计依据及相邻关系。具体入口与参考由同一发行 manifest 的 roles 登记，不另建注册系统。

默认新作者以受管引用取得完整当前稿、设计、职责和必要接口，不继承整段父历史、图片与失败日志；原作者返修继续原线程。交接提供真实差异与完整稿引用，不只换版本号。返回采用结论、问题、产物引用和待办，全文保持可读。

可发现目录、实际读取正文和父历史继承分开记录。阶段发行只能证明阶段隔离；只有实际线程证据支持时才声称子线程发现隔离。宿主无法限制的条目明确记录，不能假称已净化。没有工具能力的连续看听保持未完成，不用静帧或读取请求代替实际观察。
