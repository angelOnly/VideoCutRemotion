# 动画美术与实现判断

本页由视觉作者在新场面、美术重做或当前实现偏离设计时读取。输入是导演当前完整稿、场面关系、准确中文、模板约束、实际可用资源与相邻状态；产物写入同一份场面稿，附真实设计画面、采用参数、源码和观察范围。只改字、颜色或位置时直接处理影响范围，不重选全片风格。

## 让本片的视觉任务决定画面

先用一句话说明本段主角、需要观察的变化、必须共存的参照与观看感受，再确定对象面积、观察距离和阅读次序。“科技感”“高级”不能直接决定黑底、宋体、金属或巨型标题；把选择放进当前准确文字和模板资源中观察。统一的是明暗、色彩职责、字体语气和空间逻辑，不是所有场面同底色、同标题位置。

先摆主体、必要关系与准确文字，暂不加栏目、页码和装饰框。缩到目标观看尺寸检查第一注意落在哪里：若最亮的是底板、标题挤小主体或所有标签等权，重分面积、位置和明暗。对象数量过多时分阶段显露，不能靠无限缩字维持全部同屏。固定模板包装属于合同；作者自行增加的外壳不应压缩主要内容。

## 构图、颜色与空间

依据本场任务选并置、全幅、局部聚焦或非对称布局。比较对象保留共同基线与对应关系；关系图的线应指向正确对象并绕开正文，不能为整齐牺牲含义。场面入口、主要阅读状态、最拥挤的中途和交接状态共同设计，终帧好看不证明过程成立。

先检验主体与背景的明暗分离，再定具体色值。必要时灰度检查同亮小块是否抢焦点，回彩色确认冷暖与强调面积。颜色代表的对象或状态跨场保持；背景可以随场面变化，不把品牌色或强调色铺满所有层。文字不清时先解决字幅和局部分离，不一律加粗边、强影和高饱和。

材质属于对象：文字、图案、边缘与阴影随同一父对象变换。薄片的渐变不要画成厚鼓包；接触影随承载面距离、光向与接触点变化，物体移动不能把影子留原地。平面图形无需自动附加玻璃、金属或颗粒。复杂遮挡才读 [空间层级](depth.md)。

## 中文排印落实到真实字形

以本片主读、最长条件句、数字和代表性字幕渲染实际可用字款，检查缺字、字体回退、真实字重、笔画、字宽、行距和观看尺度。字体盒测量只辅助定位，不能证明墨迹清晰；CSS 字重值不能替代不存在的字体文件。

字太细先查回退和字款，再调整字重、对比和面积；字太宽先改布局、准确断行或选合适字款，不能横向挤压。数字与单位、专名、否定与对象尽量同组，中文标点不单独占行；不得为排版删掉会改变事实的条件。主读、标签与字幕有不同职责，不要求一样大亮，也不把旁白完整复制三遍。

普通字幕首次在本片明暗不同的背景上试排，固定字体、字号、字重、颜色、底板/透明度、内边距、描边或阴影、位置、行高、行数及框尺寸。双行规定基线与框高，避免长短句让字幕框上下跳。字幕保持最终画布坐标，不跟随场面相机、缩放或裁切；冲突优先修改主画面，确需用户要求的样式变更时全片统一。准确分卡与时序交声音/字幕作者，不能美术先删语言去适配版面。

## 从设计画面交到连续实现

新设计至少制作能够回答当前风险的真实状态，而非仅提交色卡或形容词。概念图只表达意图，实际源码预排才证明字体、资源、材质和布局已实现。先识别主体、读清关系，再检查新旧共存和向后交接；数量按风险决定，不固定凑图。

连续动作按需读 [演出方法](motion.md)，场面边界按需读 [场面方法](scene.md)。机制采用不能替换本片的视觉理由；可以为过程调整面积、字位和层级，但主要含义变化回导演。已采用机制适用的改字改色继续复用。

只读取实现当前任务需要的模板接口和组件源码，在授权区域实现。沿 wholeComposition 的全局时钟，保持章节进度、跨句对象、字幕和片尾；分镜输出不重置全片。正式冻结前停止写工程，提交改动文件、源码摘要、风险帧与待查动态范围。

## 观察后按根因修

| 真实问题 | 修改方向与复核 |
|---|---|
| 主体弱、像等权表格 | 重分主体/标题/标签面积与对比，目标尺寸复看第一注意 |
| 表面黏连、色彩脏 | 改明暗、边缘和强调面积，再回彩色，不叠更多滤镜 |
| 中文细糊、拥挤 | 核对字款回退、字幅、行距及分离方式，查看原尺寸中文字形 |
| 两端好看、中途混乱 | 改同时出现面积、遮挡与显露先后，复看完整变化和接点 |
| 场面只换字、主要关系没发展 | 回导演与视觉重设计观察过程，不靠轮换色号修复 |
| 设计具体、渲染回到默认页面 | 修组件外壳、默认值或实现遗漏，不反改设计迁就错误 |

返回实际修改与必须保留的选择，注明静帧已见、连续运动/声音未见的范围。组件无法兑现关键设计时说明具体表达损失，交导演/原作者调整，不填写虚构参数。只验证当前交付画幅，多画幅确有要求才分别重排。
