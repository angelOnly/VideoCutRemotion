# scene-planning

每个场面记录：认知任务、输入事实、持续对象、开始状态、推进动作、稳定阅读状态、退出状态与下一场接入。场面边界由主要关系或空间组织变化决定，不把 TTS 句段或每句字幕自动当成一场。

连续对象在跨句时保留身份、位置或可追踪的运动；解释中途不无因清空。建立状态给出全局参照，推进时只移动承担变化的对象，稳定状态留下足够阅读时间；退出消除不再需要的层，并把下一场需要的参照交过去。

分镜 ID 属于业务交付，章节属于理解结构，句段属于声音，渲染范围属于全局时钟，四者显式映射。最终全局帧范围在实际音频确定后形成；不能用估时伪装精确落点。
