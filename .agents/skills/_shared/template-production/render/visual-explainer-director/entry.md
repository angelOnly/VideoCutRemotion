# visual-explainer-director

本技能是导演或视觉作者的方法参考，不另建制作主流程。

先写观众在这一段需要看懂的关系，选择能直接表达它的图形语法：比较保持共同基线；分类先显示整体再分组；流程保留路径与当前进度；关系图明确连接含义与方向；因果严格保留原稿的限定，不把相关画成因果。

每次信息释放改变一个主要关系，持续保留理解下一步所需的对象与标尺。建立对象后再改变状态，让旁白指向当前可见证据；避免说完才出现，也避免提前泄露使旁白重复。文字、图形与声音分工，画面承接空间关系和变化，字幕保障语言可达，不用三份相同大段正文填满屏幕。

数据表达按需读取 evidence-visualization；状态边界按需读取 scene-planning。图表与关系来自确认稿和受管输入，资料不足时明确限定，不自行搜索补造。
