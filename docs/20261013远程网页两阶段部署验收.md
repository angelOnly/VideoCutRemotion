## 调用链及接入修改

```text
正式网页数据解读任务
→ 原网页后端 10.20.130.250
→ 新服务 10.20.130.251:8080
→ 网页字段归一化、SQLite 持久化排队
→ 独立后台 Codex + 本版 textvideo-studio MCP
→ 模板冻结 / Analysis
→ 网页回调、分镜确认
→ Render / 豆包配音 / Remotion
→ 文件发布、回调、网页粗片
```

`web-contract.ts` 只映射现有网页字段，不替换制作流程。网页不传分析版本时，渲染引用本任务最新且成功的 Analysis；较新分析尚未成功则拒绝，不回退到旧分析。回调保留现有结构，并提供网页所需顶层 `dataList` 和 `dataInfo`。

网页现有后端不发送 Bearer 令牌。部署仅允许直连地址 `10.20.130.250` 免令牌调用两个提交接口，不信任 `X-Forwarded-For`，查询、取消及管理操作仍需服务令牌。额外素材、数字人、其他模板和网页片头片尾替换没有被静默忽略，遇到不支持组合明确拒绝。
