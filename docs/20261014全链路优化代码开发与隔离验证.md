日期：2026-10-14，北京时间。

本次按《20261014全链路耗时优化最终方案》实施平台代码、技能发行与隔离测试。没有切换生产服务、覆盖已安装插件、修改正式视频任务，或通过网页提交新制作任务。原方案、用户已有 AGENTS.md 改动及原验收文档保留。

## 实现范围

| 范围 | 实现与主要文件 |
|---|---|
| Analysis 文字边界 | `template-package.ts` 支持并校验 `analysisInstructions`，拒绝缺失、源码路径、越界、空合同；`runner.ts` 将文字合同、模板版本和摘要投影到输入，完成结果绑定服务检查点；`task-instructions.ts` 升至 `template-production/6`，Analysis 不加载制作正文 |
| 阶段发现 | `codex-session.ts` 在当前 Run 建立固定技能视图，通过真实 `skills/list` 校验主会话及子会话通知对应目录；`mcp.ts` 向服务鉴权读取真实阶段，Analysis 只注册任务事实与发行读取；服务入口再次拒绝 Analysis 制作调用 |
| 后台技能 | `.agents/skills/_shared/template-production/` 是明确后台映射的维护源，入口使用 `entry.md` 避免桌面重复发现；同步生成 `skills/` 与 `skills-stages/`；Analysis 1 项、Render 18 项，排除 11 项工作流和 13 个历史包，其他插件与通用源正文保留 |
| 机制检索 | 精简后台结果与资源闭包，保留 567 条机制正文和静态图；默认 3 个候选、正文按需带图，拒绝后台 overview 和无条件全库分页；索引纯逻辑抽取后保留原 CLI 调用兼容 |
| 交接与等待 | `tool-results.ts` 持久化配音原结果，默认返回计数、异常和详情引用；媒体结果投影不重复全文；`read_render_job` 支持 `waitMs`、`afterDigest`、`details`，沿原作业状态等待，超时不重新提交 |
| 审查和预览 | 默认启用并行审片及按需预览，继续使用已有同版证据、真实名额和影响范围合同；每个动态范围须绑定问题、版本、观察者、能力和通过条件，无能力时登记待审而不生成；冻结后再次核对疑点版本 |
| 并发与渲染 | `run-work.ts` 提供服务实例内共享的公平绘图/进程预算；`template-renderer.ts` 与新增 `template-chunks.ts` 按确认分镜全局帧并行输出，完整时间线生成连续 PCM；整片复制画面码流合成，整片和各分镜从同一 PCM 全局采样边界编码音轨 |
| 恢复 | 服务串行合并完成块、PCM 与文件状态；原作业固定策略、发行、并发及渲染协议；新模式无需整片先存在即可续做，合成失败复用已核验块；旧记录保留整片切分恢复 |
| 构建缓存 | 只复用当前 Run 的不可变构建，键含完整源码与 JSON、发行、依赖、入口和资源路径；内容变化失效，损坏重建，非法路径拒绝 |
| 观测 | 分开记录排队、绘制、音轨和封装；采样 Chrome/FFmpeg 子树 CPU/RSS，明确为包含并行工作、可能漏掉短进程的采样下界；`codex-usage.ts` 使用宿主真实计数，缺数据保持 null |

主要调用链：网页提交 → 模板冻结与阶段输入投影 → 固定技能视图和可信 MCP 阶段 → 作者制作与同版检查 → 原媒体作业内领取预算 → 分镜画面、连续音轨和封装 → 全量文件复验 → 原发布与回调。

## 默认配置与兼容

- 新作业：`TEXTVIDEO_RENDER_STRATEGY=scene-chunks`；受控对照可显式设为 `whole-slices`，已有作业仍按创建记录恢复。
- 每片段绘图 4 路、每 Run 2 个片段，全局绘图 16 路、媒体进程工作额度 4。配置入口校验正整数、范围及单片额度不超过全局。
- `TEXTVIDEO_QA_PARALLEL_REVIEW=true`、`TEXTVIDEO_PREVIEW_ON_DEMAND=true`，审片上限仍为 3 且受真实宿主名额限制。
- 默认模型 `gpt-6-astra`，每次 turn 显式 `effort=low`；部署仍可通过原模型环境变量指定实际模型别名，证据记录请求模型与宿主返回模型。
- 作业恢复不会将未知、取消或版本不可信的工作换键重放；不同发行的新分块作业明确拒绝跨版续做，须保留原发行处理。
- 整片视频码流没有再次全片重编码；音频按交付文件分别编码，避免独立 AAC 段拼接。容器仍可能包含 AAC 编码延迟，不能把容器时长等同于 PCM 采样长度。
- 发布校验复用没有启用，继续全量技术复验和复制后字节比对。方案将这一项列为前面大项完成后再评估的优化，不削弱发布检查。
