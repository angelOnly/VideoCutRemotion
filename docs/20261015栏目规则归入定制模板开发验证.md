# 栏目规则归入定制模板：开发与验证

日期：2026-10-15。本轮为平台开发，按用户要求将财经栏目需求移入定制模板。没有修改正式视频任务、上传模板、部署服务器或生成本期视频。保留工作区原有两份未跟踪文档。

## 旧方案与本轮删除范围

旧方案虽然有模板文字合同和人物绑定，通用 Analysis 提示、技能及 `parseSceneScript` 仍固定认识“财小策、室长”，并将其转换为栏目内部编号。通用 Render 提示、导演技能和时间线检查还规定片头公司名来源。

本轮删除这些通用层的栏目人物、固定编号转换和公司名业务规则。不增加旧人物别名兼容、另一个配置中心或新的网页字段。平台继续保留通用的两栏理解、分镜、画面/章节/无口播标签、发言范围、配音与字幕一致性和时间线检查。

## 当前职责与调用链

1. 定制模板的 `analysisInstructions` 负责原稿标记解释；`speakerBindings` 以可见人物名为键，声明画面人物与音色；`instructions` 说明制作步骤、栏目包装、专属字段及检查。
2. Analysis 下载并冻结模板，`analysisTemplateInput` 将文字合同和人物表一起放入任务输入，任务查询同样返回人物表。模型根据模板整理原稿，Runner 使用同一冻结人物表校验返回标签。
3. 网页确认或编辑后，`normalizeWebRender` 沿任务关联的 Analysis 取冻结人物表；内部指定版本接口使用指定的 Analysis。`parseSceneScript` 按模板键名生成 `speakerId` 和发言范围，不猜人物或恢复被删标签。
4. Render 读取冻结 manifest 及其 `instructions`。配音装配继续使用同一 `speakerBindings`，将发言绑定为实际 `speaker/voiceRef`。
5. 财经模板自行运行 `renderer/scripts/verify-episode.mjs`，对本 run 的确认台词/章节和时间线检查公司标题来源。错误返回具体分镜，按模板步骤修正后重查。该检查不再是通用 Worker 的公司名门禁。
