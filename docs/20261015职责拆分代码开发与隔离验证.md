## 接口与保存边界

- 新增 `assemble_sentence_audio({assemblyRequestId,speechBatchRequestIds,planRef,expectedTimelineSha256})`。摘要是时间线文件字节 SHA-256。计划位于项目内，保存 `scenes[{sceneId,utterances?[{id,gapBeforeFrames?,captionText?}],tailFrames?,captionTiming?}]` 及可选 `chapters[{chapterId,sceneIds}]`，不重复抄写服务音频结果。
- 正式 `render_template` 不再接受 `ranges`；动态预览仍必填 `ranges`。两类请求由同源字段和严格联合校验实现。当前 MCP SDK 的根联合 Schema 无法正确展示字段，因此发现使用同源严格对象外壳，调用回调和 HTTP 服务均执行相同联合校验；已用真实 MCP 客户端验证发现与拒绝行为。
- `prepare_review` 增加 `waitMs`，整批成功且同快照才返回 `reviewId`；超时返回 `waiting_media`，媒体失败/取消/未知返回原作业诊断。相同参数续准备不创建新媒体或重复计划。静帧排队仅增加登记能力，同 Run 实际绘图仍逐项进行，正式导出和装配保持排他。
- `read_review` 增加 `afterDigest`、`waitMs`，返回 `statusDigest`、`timedOut`。查询计数不参与状态摘要。断线、Run 取消与服务关闭释放监听。
- `submit_review` 增加可选 `issueResolutions[{issueId,evidenceId?,resolution,note}]`，处置范围必须有当前真实观察。旧图变化不能通过空 `issues` 数组关闭问题；建议保持可见但不强制返修。
- 装配记录保存前时间线、作者计划、音频绑定、真实时间变化和复用计数；审片现有 SQLite 记录保存准备、首次领取、最后提交、查询/超时计数及观察/复用数量。媒体、发布和回调沿用原日志与记录，不新增观测平台。

## 失败与恢复

音频字节错绑直接失败；旧测量凭据仅补测原本地音频，不重新请求供应商。装配保留视觉对象、动作事件、BGM、SFX、包络与源码；时长变化只报告影响，不拉伸全部动作。原键成功重放只查结果，提交中断核对记录与实际输出摘要；计划或时间线冲突保留原记录并返回真实差异。

章节视觉起点保留；审片包独立把首末包装计入覆盖。共享源码、字体、未知依赖和无法分开的章节语义仍保守扩大复查。所有当前合同允许的交付保持静帧流程，不新增强制听审、连续观看、人工审批或待审状态。

正式交付核对 Run、attempt、令牌、发行、输入、模板、源码、原清单与 checks。缺失/损坏/错身份清单明确失败，不续模型伪造清单；临时 I/O 沿原 handoff 恢复；未知不重放，取消不发布。重启可确认成功交付时先恢复服务交接，确需恢复创作时仍保留原子作者线程保护。发布完成但结果事务中断和回调失败均沿原结果恢复，不重复制作。

## 已知代价与未执行范围

本轮代码与候选发行不等于生产部署；未发布新模板到模板服务，未切换生产插件，未再次发起网页整片制作。新正式无 ranges 接口要求模板声明支持的时间线合同；历史冻结作业仍按原发行、快照与固定范围恢复，不进行迁移。

Run 排他与摘要检查不能完全隔离作者直接写文件，装配及冻结时仍须协调停止同文件修改。有界等待超时后需沿原参数续查；未知共享依赖仍可能扩大复查；音频时长变化仍需视觉作者重新校准。

同数据迁移、装配帧界、隔离媒体的逐帧/采样边界与恢复行为已做技术核对。没有执行原 134 秒工程全片的连续看听、整段解码对照或优化前后端到端计时，不能据此宣布同效果提速比例，也不能宣称已解决原样片后半场动作不足。实际未观察范围继续如实记录，不新增生产门禁。
