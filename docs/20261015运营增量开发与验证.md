## 实现与调用链

两栏输入 → Analysis 返回含标签的可编辑分镜 → 原网页修改并提交原有 dataList → normalizeWebRender 沿 taskId 找最新一次成功 Analysis → parseSceneScript 从当前文本计算实际台词与导演信息 → 保存确定的请求 → 原配音、装配、核验、审片、渲染与交付。

Analysis 每镜只返回 id、content、dur、durationSource。content 示例：

```text
【财小策】这家公司为什么值得关注？
【室长】先看它的主营业务。
【画面：展示主营业务构成图】
```

支持【财小策】、【室长】、【画面：说明】、【章节：标题】；纯画面写【无口播：3秒】【画面：说明】。程序只解释明确标签，普通括号、标点、数字与英文保留。两栏的采用、替换和参考说明放在原有 context，不再要求逐字符分类。

服务保存的 request.dataList 中，content 为实际台词，submittedContent（有标签时）保留用户提交原串，directing 为代码从本次文本计算的内部发言范围及画面信息。网页不传、不维护内部字段；不使用旧 Analysis 的偏移或隐藏人物覆盖当前稿。当前镜头集合、次序和台词参与现有幂等摘要。原始要求由任务记录读取，已执行的改稿要求不重复执行。

网页仍提交原有 taskId、templateId、intro/outro 与 dataList（id/content/dur/extraData）；不新增分析版本或要求字段。内部保存的 basePlanVersion 由服务关联确定，受理后恢复不重新查询最新版本。原有内部指定版本、指定成片修改 API 保留，没有新增网页协议模式。

## 失败处理

未知或破损标签返回 SCRIPT_TAG_INVALID 并指出分镜；纯画面缺时长/说明、带台词或时长越界拒绝受理。最新一次 Analysis 未成功时返回 BASE_ANALYSIS_INVALID，不跨过失败的新分析取旧结果。错误在请求入库前检查，不创建半成品 Run。

句段跨人物、实际音色不符仍为 SPEECH_BINDING_INVALID；台词缺音频、字幕或实际时长仍失败。无口播只接受明确标签生成的类型，不能从 TTS 失败倒推。原幂等、取消、恢复、冻结快照、媒体校验和交付逻辑继续使用。

## 已知代价与边界

- 可见文本中增加少量标签，用户能直接修改；不增加专用人物编辑器。拆镜后如果新镜仍要固定人物，应保留对应标签；程序不会依据旧位置猜回人物。
- 【】是本次约定的指令分隔符，未知标签会报错；普通中文或英文括号不受影响。服务语法解析不等同于模型的语义理解证明，分析采用说明由原 context 保存。
- 现有网页自身的文本裁剪、至少 10 字输入限制以及拆并文本行为保持原样；服务只能保存实际收到的内容。
- 网页没有分析版本字段，不能精确区分旧标签页；沿原有最新一次 Analysis 必须成功的规则处理。需要重开页面取得最新分析时不自动补回旧稿。
- 发布需同时切换本项目服务和配套财经模板；不改网页或转发服务。候选构建不代表已经部署。
