# 模型、推理等级与加速档部署配置

Worker 通过部署环境读取模型设置，并用于 Analysis 和 Render 新会话。已结束任务不重新执行。

| 环境变量 | 未配置时 | 本次 Luna 对比测试 |
| --- | --- | --- |
| TEXTVIDEO_MODEL | gpt-6-astra | gpt-6-luna |
| TEXTVIDEO_REASONING_EFFORT | low | xhigh |
| TEXTVIDEO_SERVICE_TIER | 不额外覆盖宿主设置 | priority |

`priority` 是服务器模型目录中 Fast「1.5x speed」档的实际标识。官方说明见 https://learn.chatgpt.com/docs/agent-configuration/speed 。加速档作用于模型服务，不修改语音速度，也不保证整条视频生产流程缩短至固定比例。

原先 `codex-session.ts` 将每轮 effort 固定为 low，导致只改宿主配置无法启用极高推理。现改为读取部署配置；线程默认推理等级与每轮显式参数使用同一个值，原生章节作者沿线程默认值继承。加速档通过 thread/start 和 turn/start 的现有 serviceTier 字段传入，并开启宿主 Fast 功能。未增加模型自动替换或失败回退路径。

`plugin-evidence.json` 保存请求的模型、推理等级和加速档，以及宿主返回的模型。真实任务还应核对宿主 turn_context，不能仅凭部署环境证明请求已被宿主执行。

发行版本 0.1.28；修改文件为 config.ts、codex-session.ts、执行控制器测试及发行物。测试通过假宿主实际接收的线程与轮次参数验证 low 和 xhigh/priority 两组设置，同时验证媒体等待纠正后续轮不丢失配置；失败仍沿原任务恢复机制处理，不换模型掩盖问题。
