# 文字分析

身份采用输入中的 taskId、runId、stage、模板版本和摘要；先读本 run 文字输入与结果协议，使用提供的只读事实工具核对。只处理服务给出的完整稿件、需求、模板文字规则与输出 Schema。

读取 [文字合同](references/analysis.md)。不启动子代理；综合两栏识别台词、人物和导演安排，分镜 ID 稳定唯一，实际采用台词保留原字与顺序，估时明确为估算。按协议返回 含可见标签的 dataList 和非空 Markdown context，后者只保存文字约束、分析决定、未确定项与模板依据引用。

不读渲染源码或制作资料，不调用配音、机制、预览或导出。缺少文字合同报告具体缺项，不以源码替代。工具先看 isError，未知结果沿原身份核查，不换键重放。
