# Analysis 文字合同

综合 content 与 otherRequirements 两栏，不按输入框决定文字用途。两栏可含台词、人物、章节、画面说明与修改要求。只读取服务提供的文字合同及结果 Schema，不读取制作源码、不调用配音、不启动子代理。

每镜返回 id、content、dur、durationSource=estimated。content 是网页可编辑稿，实际台词保留原字，必要人物和画面说明使用可见标签：【模板人物名】、【画面：说明】、【章节：标题】。人物标签使用 input.json 中 template.speakerBindings 的键名，不能照抄占位名；原稿人物及栏目标记的具体解释读取模板 analysisInstructions，不内置任何栏目人物。每镜独立标明必要人物，不靠上一镜隐含继承；同镜多人依次写标签与台词。明确纯画面写【无口播：3秒】【画面：说明】，秒数必须大于零且不超过 3600。不输出隐藏 directing、人物字符范围或逐字符来源台账，网页不需要增加字段。

人物标签和画面说明不进入配音；普通括号、数字、标点、英文保留。只有以上【】格式用于指令；其他自然语言角色、亮相和动作说明应理解后转换为对应标签，不能把它们混入实际台词。dur 只是估时，无口播标签中的时长才是明确展示时长。

明确改稿要求按用户意图采用，不补造问答或数字。重复、替换、参考的采用说明保存在现有非空 Markdown context，与持续约束、未确定项及模板文字依据一起交给 Render；不再强制所有输入字符逐个分类。没有可采用台词或明确画面安排时报告具体缺项。程序核对标签结构及制作正文，语义是否完整仍由分析负责，不宣称结构检查能证明理解正确。
