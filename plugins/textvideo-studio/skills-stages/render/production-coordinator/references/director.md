# 确认稿的动画观看组织

导演接收完整确认稿、ID 和顺序、需求、模板固定包装与实际能力，负责整片主线、主要视觉采用、章节与跨段关系。此链路不自动改写确认正文；能在画面和释放节奏中解决的问题先在当前范围处理，确实需要改稿时指出具体句段、原因和代价并回主任务，不自行增删事实。

## 将稿件变成可观看的关系

先回答观众开始知道什么、为何愿意继续、结束时应理解什么，再为句群确定认知任务。开头可以结果先行、问题、具体差异或稳定观察，不能把固定“三秒钩子”套给所有内容。结尾使用前文已建立的关系完成任务，不自动增加总结页或结束语。

找到内容中可见的变化：差异需要共同条件和比较尺度；累计需要保存上一步结果；流程需要方向、当前位置和回应；关系解释要区分分类、相关与因果；下一关注来自当前对象时可以共存后接管。题目名称不决定图形类型，“有比较”不自动变成两个文本框。

在当前稿中把句群、业务分镜、章节和场面对应起来。分镜 ID 用于交付，章节组织理解，场面承担观看，TTS 句段承担语言连贯，不能相互机械切分。场面可以跨句持续，也可以在同一业务分镜内多次改变状态。

## 给专业作者可以继续制作的输入

每个主要场面交清：准确句群与分镜 ID、观众任务、主次对象、必要事实/限制、开始和结束状态、持续参照、正文/画内文字/字幕的分工、声音意图、进入和退出。具体色值、像素和曲线由作者深化，不要求导演预写全部实现参数。

视觉与声音具备各自输入后同时推进。声音先按模板音色形成自然句段，视觉可以用估时排主要过程；实测音频回来再校准有效阅读和交接。初稿估时不是不可变锁定，确认正文和用户明确的总长/包装边界仍需保持。

确认采用时接回完整设计与实际代表状态，重新经历前段、本段和后段。检查观众凭什么识别对象，结论是否抢在必要过程前，比较参照是否丢失，前文已讲清的东西是否被重复建立；跨章是否都用相同展开收尾。决定具体提前、推迟、保留或退让的层，不用统一加速替代节奏设计。

## 先解决会批量传播的问题，再完成整片

初步试排先完成主要对象和动作，重点验证信息关系、固定包装与关键接点；占位标题不能证明解释成立。代表段须含建立、主要事件、阅读和恢复，不只做精致入场。声音承担节奏时应有真实可听材料，不能把无声样段当声音包装通过。

接回代表段后列出可以沿用的设计、需要返修的关系、下一项具体制作范围以及整片未完成部分。先修会扩散到全片的字体、布局或时钟问题，再扩展其余场面；其他场面按自身任务发展，不复制统一时间槽。代表段只证明实际覆盖，不能宣告整片完成。

导演关注全片起伏、章间切口、片头片尾、跨场持续对象与美术语义；单元审片者检查各自同版具体画面。对冲突结论给出整片依据，不让多名审阅者并发改源码，也不重复逐张重查已有可靠证据。

## 集中返修与责任回传

反馈写成“哪个状态/范围发生什么、妨碍哪项理解、准备变成什么过程、必须保留什么、相邻哪些声画受影响”。不要只说更高级或更紧。主要关系改变时返回更新后的完整场面稿；局部比例、字位和曲线交原作者继续。

- 观看没有发展、结尾没有完成任务：导演调整画面任务与次序，保持确认正文限制。
- 主体、中文排印、颜色和共同构图不成立：视觉作者修改设计；设计明确但漏层、错时钟、错裁切：原实现修源码。
- 新旧同时出现拥挤、比较参照消失或接管断裂：原演出作者修中途与共同状态，不默认删掉组合目标。
- 读音、语速、句段拼接或音乐遮蔽：声音作者给实际修订和实测时长，相关字幕/动作同步更新。

先修事实、语义、声音和主要关系，再修局部包装，最后处理可选美术建议。未实际看听的内容保留待审；已知问题不能靠加长评价报告关闭。可选建议不成为无限返修或额外审批。技术失败与专业观感分别记录，真实观察不足不伪造成通过。

交回同一份完整当前稿、采用状态、跨段接口、实际改动、作者责任和待审范围。需要连续验证时说明最小范围、具体问题、实际观察者及通过条件，交主协调按 [检查合同](review.md) 提交。

## 当前确认输入的采用边界

网页沿原接口提交可见分镜文本，服务在受理时解析本次标签并沿任务记录关联分析。request.dataList 的 submittedContent（存在时）保留用户提交原串，content 是实际台词，directing 是从本次文本重新计算的内部信息；网页不维护这些字段。以当前镜头集合、顺序、台词和标签为准，不从旧分析恢复删镜、旧句或被删标签。analysisInput 是原始两栏，analysis.context 是初次采用说明；已采用的替换指令不重复执行。otherRequirements 沿任务记录传入，持续要求补充未指定部分；明确矛盾时报具体分镜，不暗改请求。没有指定人物时沿模板安排，不按问句猜已指定人物。

指定 speechTurns 按人物边界拆现有自然句段，保留 turnId，segmentId 继续作为 utterance.id；不跨人物、不按问号猜角色。visualDirections 与 chapter 交视觉作者，绝不拼入 TTS。kind=visual 只用明确画面与 durationSec 推进，不能从配音失败推断无口播。

片头公司名由当前采用台词或章节标题确定，保存 scene.intro.companyName 与 companyEvidence={sceneId,field:'content'或'chapter',start,end}，范围为当前正文 UTF-16 半开区间；多家公司主次不明或没有公司用 null。编辑换题后重新核对，不引用原模板标题或旧任务。只在原片头范围叠字，保留素材、声音及全部原时序。
