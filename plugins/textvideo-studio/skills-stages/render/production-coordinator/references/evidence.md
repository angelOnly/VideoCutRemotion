# 数据与证据的动画表达

本页只使用确认稿和受管输入已经提供的真实依据，不启动外部搜索。先把当前主张、来源位置、准确内容、单位/时间/比较口径、能支持与不能支持的结论对应起来。材料不足时说明具体缺口和未知，回导演处理限定，不画假数字或伪页面填空。

## 先建立身份，再聚焦有效内容

首次出现的文档或页面需让观众知道正在看哪份材料，再提示目标、聚焦、高亮、稳定阅读和退出。身份已在前文建立时可直接到相关局部，不能每次重复全貌。整页过小读不清、直接裁句失去条件或大面积高亮没有重点，分别改观察范围、建立过程和高亮范围。

原句、编辑摘要/翻译与本片解释分开；否定、前提、时间范围、单位和比较基线不能因好看被裁掉。高亮和放大层共用原图的坐标/缩放，接管前对齐内容、尺寸与位置，让观众理解仍是同一份材料。制作备注与内部来源记录留幕后，实际要求的引用/披露以及改变含义的条件准确交代。

## 图表编码必须与数据含义相符

先确定坐标、单位和比较对象，再出现数据和结论。相同长度不能代表不同尺度，动画起点不能冒充真实零点；截断坐标需要清楚表达，面积编码与长度编码不能混用，累计值与增量必须区分。相关不等于因果，短时段或小样本不能画成确定普遍规律。

用逐步建立和保持参照帮助观众比较，不为震撼夸大比例。复杂图表分成连续状态，保留当前理解需要的基线/图例；读数与结论留足时间，字幕避让但不删实义正文。数据或来源冲突时保存冲突与适用范围，不只选最容易画的一项。

证据画面退出要承接“它说明什么、仍不能说明什么”的下一层理解，而不是突然换题。交回来源文件与位置、主张绑定、必要限制、图形编码、阅读状态、核过的数字和未确定处。生成图、动画演示或截图标题不能自动提升证据强度。
