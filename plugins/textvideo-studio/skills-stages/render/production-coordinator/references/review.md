# 同版检查、返修与按需预览

作者结束写入并提交关键风险点，主协调一次冻结同版静帧。preview_template_frames 使用唯一 renderRequestId 与 1～12 个唯一全局 frames；12 是上限。read_render_job 返回 sourceDigest 和 readyFrames 后才可分派观察。图形中间态、长中文、固定包装与章节切口优先，原尺寸图检查细节。

## 服务领活、观察与连续提交

主协调调用 prepare_review({renderRequestIds,phase})，phase 固定为 pre_export，只分配静帧布局与字幕布局检查；只有服务无法从作业或同快照核验记录定位时间线时才补 timelineRef。Runtime 依据配置和宿主实际名额启动有界的只读审片会话。每个会话只绑定当前唯一计划，凭证来自服务环境，不由模型自报身份，不继承制作、生成与发布权限。

审片者调用 claim_review_work({}) 获取当前包；重复领取返回原活动包。实际读完对应证据后调用 submit_review({assignmentToken,observations,issues,status})。observations 每项填服务给出的 checkId、evidenceId、简短 note；静帧使用服务登记的帧号，不填连续媒体 range。issues 填 checkId、evidenceId、severity、problem，必要时提供问题 range；没问题用空数组，不填占位问题。status 仅为 partial 或 complete。

不手填 runId、审片者身份、文件摘要、分派代次或 submissionId。服务核对当前分派、证据、观察目的和已查看图片；不同 checkId 的覆盖不能互相代替。partial 保存已完成范围并返回剩余要求；complete 成功后原子返回 next，审片者直接继续，不等主协调逐包登记和派单。工具重试使用原分派与相同正文，读取已保存响应，不另造身份。主协调调用 read_review({reviewId}) 查看简短汇总、剩余和阻断问题，具体异常才展开材料。

新 Run 不使用手填 QA JSON 或 review.cjs assign/result 作为主状态。审查断流保留已完成覆盖，撤销旧代次后只接替未完成只读范围；过期分派和跨版迟到结果留档，不能覆盖新结论。参数拒绝只纠正明确未执行字段；证据部分不可读只恢复该读取，不能把打开播放器记作已看完。

返修交回实际修改文件与范围，服务从快照真实差异核对失效范围。局部字幕文字或换行复查该卡及换卡边界；全局字幕样式才扩大布局检查，不因字幕变化自动重审全片。普通场景变化检查当前完整场景，有明确源时钟、遮挡或接管依赖才扩展相邻范围；共享组件、全局时序和固定包装按真实影响展开。未知依赖保守保留复查，不能仅凭作者自报 local 复用。只复用仍有效的静帧观察结论。

按需预览开启时先记录 sourceDigest、具体疑点、最小全局帧范围、consumer、真实看听能力和 passCriteria。没有连续观察者则标记 professional_review_pending，不生成无人消费的大范围视频。render_template 的 previewOnly=true 请求须按每个范围附 previewRequests，字段为 sourceDigest、question、fromFrame、toFrame、consumer、passCriteria、needsVideo、needsAudio、continuousVideoAvailable、continuousAudioAvailable；范围与 ranges 一一对应。有限片段并发由服务控制，不能自行启动额外编码。已有同版核验整片直接观察该文件。

静帧、连续画面、音频与技术结果分别报告，静音代理与探针不能证明完整视听。连续观察发现问题仍回原作者修订；最终源码须再次核验实际音频，再冻结导出。

## 专业观察方法的适用边界

下表保留专业方法参考，不是本 Worker 的必做清单。当前流程仅执行静帧检查，不分配听审、连续观看和声画同步任务，不因未执行这些方法阻止导出或回传。五轮是不同观察任务，不是要求五个代理或五次重复加载全片。主协调根据真实能力、已有证据与当前疑点分派；同一观察者可兼任但分别记录方法和范围。首次观看轮应在读导演预期答案前进行；其他轮可按问题组织。没有足够连续视频或音频能力的轮保持 inconclusive，不填模拟通过，也不为了凑满五轮生成无人观察的视频。

| 观察轮 | 实际操作与判断 | 问题去向 |
|---|---|---|
| first_viewer（首次理解） | 未看预期答案时按当前顺序观看，记第一注意、何时认出关系、等待/迷失、主要变化和结束；已熟悉稿件就注明。用实际线索说明理解，不声称测得留存或共鸣 | 主线、重复建立、跨章和结尾回导演 |
| audio_only（只听声音） | 实际听当前音轨，查错读、残句、拼接、语气重置、音量、停顿、音乐起伏、效果声与无意静音；声音本身不成立不能用画面分散注意 | 声音作者；错正文同时告知导演 |
| mute_visual（静音看画面） | 先正常速度看第一关注和关系推进，再用原尺寸静帧定位中文字形、图表、遮挡、重复、危险中途；静帧只能证明对应状态 | 视觉或原演出作者；实现偏离设计回源码 |
| audiovisual（完整声画） | 带声连续查看语义落点、字幕换卡、效果声可听起音/主攻击、音乐遮蔽、章节交接和片尾；分别正确但互相竞争也要记录 | 动效与声音原作者协同，跨段问题回导演 |
| mode_specific（动画解释专项） | 核对认知任务是否完成、对象与共同参照是否持续、关系是否渐进、数据基线与限定是否诚实、场面切换是否来自任务变化；不能只查有无特效和错字 | 导演、数据/证据及视觉负责人 |

每轮在当前检查包中回传 checkId、evidenceId、实际观察范围、简短观察与未知；sourceDigest 和媒体位置由服务绑定。只点播放、探针可解码、波形有峰值或路径存在，都不能证明实际看听。代表段通过只覆盖该段及当前版本，不能扩大到整片或最终文件。

## 先观察实际作品，再对照设计

首次观察后读回当前采用的完整场面、演出和声音决定，核对是否实现了主行为、比较参照、入口、中途、阅读和退出。机制编号存在不证明动作兑现；只剩渐显、微移和换字时指出原本哪项关系没有发生。组件能渲染而设计效果未实现，属于需要返修的具体差异。

渲染与设计不符查字体、默认外壳、父变换、图层、时间与绑定；忠实实现仍不好看回原设计，不删除设计要求后补写“通过”。各段独立成立但组合断裂回导演。中文问题查看真实字款/回退、标点、数字单位、行距与目标尺度；两端好看中途拥挤则定位共同出现时的主次、面积和显露，不统一减慢全片。

## 问题写法、等级与集中返修

问题按上述最小字段提交，problem 说明具体观看影响；需要定位时才给半开范围，不强制填写期望变化或长篇修复计划。记录使用既有 blocking / warning / suggestion 严重度；事实错误、严重断义、重复人声、关键内容遮挡、黑帧或缺音轨按实际影响标阻断，显著损害理解但尚有可用结果标警告，纯可选尝试标建议。inconclusive 是证据状态，不是虚构失败或通过。

先修事实、语义、声音和主要场面关系，再修局部排版、动作和混音，最后处理小材质与可选建议。主要关系回导演，构图与字形回视觉，中途竞争和接点回演出，时钟与实现遗漏回源码，听感问题回声音；主协调不擅自用简单淡入替代原表达。

对于高影响疑点，可用同一文字与范围比较当前、最小修复、更强处理或取消该效果，判断理解/注意收益和阅读/连续性代价，不因效果存在就保留，也不把最容易通过技术检查的选择默认当最好。返修回原作者集中完成，审片者只读；重复问题归并后再交接，不让作者收到互相冲突的零散指令。

复查同一上下文的新旧结果，说明问题是否解决、付出了什么代价及剩余未知。未变范围复用必须有可信摘要与影响依据；共享组件、全局字幕样式、全局时序和固定包装按真实影响扩大复核。观察缺失如实保留，真实已知技术/用途阻断按合同处理；可选审美建议不另增审批，不要求用关闭所有意见换取导出。

本流程完成条件：分配的静帧已查看，已发现 blocking 已修复并复查，warning 明确处置，suggestion 可保留。专业看听缺失只写检查说明，不产生 Worker 待审状态；正式媒体成功后沿导出合同直接交付。
