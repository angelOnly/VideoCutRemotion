# 模板视觉制作的接口与读取范围

新场面或美术重做读取完整[美术方法](../../visual-treatment-planning/references/art-direction.md)，包括中文排印、材质、构图与返修；选择外观时补读[美术方向](../../visual-treatment-planning/references/art-directions.md)相关部分。连续场面制作读取[演出方法](../../motion-brief-writing/references/performance-design.md)和[动效时机](../../effect-timing/references/timing-design.md)，坐标与源时钟读取[素材空间与时间](../../remotion-production/references/material-space-and-time.md)。纯局部修字沿现有设计，只读影响范围，不重读全套。

以当前完整稿、模板授权区域、实际资源和相邻状态为输入。固定资源、字体、Logo、头像与包装遵守模板合同；方法参考中的作品、绑定和源槽位是设计与数学概念，实际实现读取当前模板组件接口，不承诺通用项目的旧生成或写入能力。

采用完整 Composition 与全局帧。章节局部时间由全局帧减起点得到；技术分块继续采样同一完整作品，不重置对象或源音视频。普通字幕在最终画布独立渲染。复杂空间或证据表现按需读[空间层级](depth.md)或[证据方法](evidence.md)。

只读取实现当前任务需要的模板接口和组件源码。冻结前停止写入，交回实际改动、源码摘要、风险帧和待查连续范围。设计不足回原作者；模板能力缺口交具体表达损失，不发明字段。
