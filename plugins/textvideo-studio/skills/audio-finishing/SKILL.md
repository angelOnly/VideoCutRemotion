# audio-finishing

以稳定的主旁白为基准，先处理句间响度、停顿和音色连续，再决定模板已有音乐是否支持段落意图。不能让音乐掩盖不清楚的正文，也不自动搜索额外素材。

音乐进入、退出与段落起伏对应，旁白期间压低并保持平滑恢复；效果声用于明确动作或状态变化，不每个字都加音效。避免突兀截尾、密集叠加与跨场响度跳变，留出自然余韵。

使用最终音轨听查开头、句段接点、章节切口和结尾；记录真实听过的范围与设备/能力限制。技术校验、波形、静帧与静音代理不能证明听感通过。最终连续音轨由服务按固定导出策略处理，作者不自行拆片拼音轨替代正式流程。
