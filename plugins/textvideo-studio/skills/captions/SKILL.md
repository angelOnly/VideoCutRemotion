# captions

读取 [声音与字幕](../production-coordinator/references/audio.md)。字幕文本必须对应实际可播放语言，最终 spoken text 拼接对应确认稿。优先按语义短语分页，保留否定、数量、专名和限定条件，避免把紧密词组拆到两卡。

首次确定全片统一样式，遵守模板字体、字号、行数、对比度和安全区。字幕维持稳定阅读位置，画内解释标签由视觉作者设计；两者避让，不能把字幕大幅跳动冒充动效。

时序来自真实音频句段；没有逐词证据时不得声称词级对齐。检查换页前后留白、闪卡、超长句、首尾截断及跨段连续。局部修字影响换行时复查真实画面，音频改变时更新对应字幕及后续时序。
