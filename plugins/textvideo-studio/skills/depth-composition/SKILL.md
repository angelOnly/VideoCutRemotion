# depth-composition

复杂场面先标明背景、解释主体、前景强调、固定包装和字幕的层级与占位。层级服务当前关系：遮挡必须有可理解原因，关键标签与连接线避免穿越正文；不要用无限提高 z-index 修复布局问题。

为运动留出真实路径和安全区，检查缩放、移出、遮挡揭示的中间态；静止画面无重叠不代表路径安全。图形角色和模板头像可作为参照，不能因此扩展成人物生成流程。

多画幅仅在当前输出合同要求时处理，按内容重新分配空间，保持文字实际可读。交回层级、路径、关键风险帧与观察结果；问题影响跨场持续对象时同步导演。
