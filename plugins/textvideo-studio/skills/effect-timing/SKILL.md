# effect-timing

用实际音频句段边界区分语义意图和时间精度；没有词级证据时仅声明句段级，不把均分字符伪装精确对齐。

每个动效包含建立、动作落点、稳定阅读和退场。建立略早于观众需要辨认对象的时刻；落点配合真实重音或语义转折；阅读时避免持续抖动；退出给下一状态留下方向与空间。运动速度依距离、对象重量感和认知复杂度调整，不用一种缓动覆盖所有行为。

先保障语义可读再追求节奏。语言过密时通过场面持续、信息分批和简化次要装饰处理，不擅自删确认稿。每次改实际音频或语速重算后续帧范围，局部偏移说明是否影响邻接切口。
