# evidence-visualization

将每项主张绑定用户提供或模板受管材料中的真实依据与范围；资料不足时保留不确定性，不以生成图像、假数字或外部搜索补造证据。

图表保留单位、时间、来源和比较口径。比较采用一致尺度；截断坐标、比例面积、累计与增量须清楚表达；相关关系不画成确定因果。高亮应聚焦依据，不能隐去会改变结论的限定。

展示先建立全局参照，再聚焦数据变化，最后给出与旁白一致的含义。为数字和来源预留阅读时间，复杂图表拆成连续状态而不是缩小整张图。回传真实依据引用、限定、图形编码和未能证明的部分。
