# known-errors

只读取与当前诊断相符的段落，不在任务启动时预读所有错误。

- 参数拒绝：确认工具明确未执行，按实时 Schema 与字段诊断纠正；不能把输入错误报成服务缺陷。
- RENDER_BUSY：本视频已有媒体作业，读原作业或使用服务等待机制；不换编号绕过额度。
- 幂等键冲突：同键不同输入应拒绝。先核对实际输入与既有记录，只有真实新修订才使用新键。
- 配音 validation_failed：已有音频时使用 retry_speech_validation，只重做本地核验。unknown 沿原 job/run 核查，不新发供应商请求。
- 正式媒体明确失败：先读原 renderRequestId、失败范围与冻结摘要；符合条件时使用 retry_render_slices，仅恢复缺失或失败部分。取消、unknown、损坏快照不盲重放。
- 机制来源过期或无结果：过期重新查询并核读采用项；无结果调整关系描述或自行设计，不引入历史资源。
- 辅助审查记录失败：保留请求、诊断与已观察证据，只恢复失败的记录操作；不清空同版计划，不把记录失败当成媒体失败。

临时连接失败先检查状态。只有确认平台自身缺陷阻断任务才沿现有修复渠道报障；无依赖工作继续。
