# production-coordinator

本入口只处理 Render。Analysis 使用独立的文字阶段视图。

先读 [基础事实](references/base.md) 与 [协调合同](references/render.md)；当前输入已完整提供的基础事实不重复读取。建立持续负责的导演；确认稿已具备时让视觉、声音作者同时处理各自已具备输入的工作，不默认重写文案或取材。子代理不递归分派，只有主任务提交正式工具与写入记录。根据真实名额续接原作者，不能用审计字段冒充真实委派。

导演交回完整稿的章节、场面及跨段关系；视觉按实际模板接口实现；声音按真实音频形成时序。每次交接只带当前完整稿引用、源码摘要、实际差异、职责和未完成事项。导演与视觉必须能理解完整内容，不能用摘要替代稿件。

进入检查时按需读 [检查与交付](references/review.md)；工具失败才读 known-errors。已有负责人继续受影响部分，不另建重复任务。
