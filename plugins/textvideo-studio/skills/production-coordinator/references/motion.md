# 连续演出与机制采用

视觉作者在新建或实质重构运动关系时读取。美术已成立的局部改字、改色和小偏移直接修当前实现，不重新检索整套机制。

## 设计过程，而非列效果名

从当前准确句群与场面状态出发，明确谁发起、谁跟随、什么保持、什么被揭示、最后由谁接管。入口和目标状态先成立，再设计最容易失去主次的中途：位置、轴心、姿态、投影面积、遮挡解除程度、可见文字与注意分配。两端线性插值不能替代这个判断。

过程动词必须在画面中兑现：移动抵达接收位置，揭示通过遮挡解除或观察变化，比较保留共同参照，回收处理先前对象。大动作中不急着摊开小字，到可读投影面积才显露；阅读来不及先改字量、面积和交叠，而不是把整段统一放慢。

明确场面观察层、对象层与局部显露层。文字、边缘、图案和影子跟随同一父对象；多种动作共同修改属性时指定计算顺序或分层，防止后一个 transform 覆盖前一个。跨层接管保持对象身份、内容、位置、尺度、朝向和时间一致，不在每个技术片段边界归零。

速度围绕辨认、动作和阅读安排准备、发力、通过、减速与收势，并非每个对象都必须凑齐阶段。主对象可以果断，附属层延后，背景观察更稳；需要阅读处稳定，连续通过处核查速度衔接。位置和尺度的过冲不能被透明度使用的 0～1 裁剪误删。

## 按需核读并改造成本片设计

新关系需要参考时调用 search_motion_mechanisms，通常先取 3 个候选，核读入围的 1～2 项；先匹配行为、持续参照、观察与接管，再考虑力度与性格。已有 ID 直接读取；必要时 include_storyboard=true 观察空间过程，静态图不证明速度或声音。

采用写入当前演出稿：机制 ID、source_sha256、本片对象映射、保留动作、舍弃动作、补做的接点、实际观察范围。不能仅填编号就称已采用，也不复制不适合本片的附属外观。多机制组合说明共同状态、重叠时谁控制哪个属性、上一动作留下什么以及下一动作缺什么，不要求每段固定数量。

无结果先换关系描述或筛选，仍无匹配就由作者完成本片设计并如实记录，不伪造 ID 或打开其他资料路线。局部返修保持原机制仍有效的部分，不重复搜索以替代真实观察。

## 校准声画并验证危险中途

先决定新重点何时可辨、何时必须读清，再反推启动、旧重点退让、内部显露与收势。初稿相对秒数可表达交叠，实际音频回来后按可靠句段边界落到全局帧；没有词时间就不伪造逐字精确落点。

取得入口、危险中途、阅读和退出的真实源码画面；有具体连续疑点且有观察能力时看入口前、完整变化、读清后及相邻切口。看得见才判断速度、惯性与衔接，未观察的范围保留待审。

| 现象 | 优先定位 |
|---|---|
| 动得顺却发飘 | 发起/跟随关系、姿态、加减速分布和收势 |
| 终帧好看但中途拥挤 | 投影面积、遮挡、可见文字与第一关注 |
| 字或影子停原地、组合动作互相覆盖 | 父子归属、局部偏移和属性求值顺序 |
| 突然停住、进入退出截断 | 速度衔接、挂载窗口、局部时间与交叠 |
| 设计照做仍平淡 | 原作者重设计观看过程；设计具体但遗漏则修实现 |

仅当接触/堆积确有作用时处理接触点、非对称姿态、逐渐损失能量及落稳对象的持续遮挡。任意帧必须可重建，不能依赖上一播放帧或用固定随机种子掩盖有状态模拟。交回完整演出、源码与参数、事件时序、修改影响和真实观察，不用函数名或文本检查证明演出完成。
