# 动画场面状态与边界

导演或视觉作者在新建场面和主要关系改变时读取。本页产物是当前稿里的场面段落，不要求额外登记同义表格。

每场先确定一个主要认知任务，说明观众进入前已知道什么、这一场要观察什么、离开时增加什么理解。边界由关系或观察方式改变决定，不由句号、字幕换卡或 TTS 句段自动决定。业务分镜 ID、章节、场面与句段保持显式对应。

依次写清入口、推进、稳定阅读、退出：入口保留熟悉参照并建立新对象；推进改变关键关系且让观众追踪对象；稳定状态留下比较或阅读时间；退出处理不再需要的层，把下一场所需对象和方向交过去。对象可跨句持续，换卡不清空画面。

最危险状态往往是新旧同时存在、遮挡刚解除或结论开始响应时，不一定在时间中点。标出那时可见文字、投影面积、第一关注与退让层。若比较丢了共同基线或过程只剩轮流出现的文字，就重新设计状态关系，不能只加转场。

连续时长先按句群估排，实测声音回来后校准可辨、可读和退出时刻。稳定不等于空等：阅读、比较和余韵可以停留；语言继续而画面已无任务时，交导演调整信息释放或场面持续，不能用背景粒子假装发展，也不擅自删确认稿。

交回状态、持续对象、全局范围、进入/退出接口、关键风险帧与动态疑点。主要含义或跨章顺序变化回导演，局部状态细化由原视觉作者继续；当前素材和组件不支持关键关系时说明具体缺口，不能把占位当完成。

## 当前确认输入的采用边界

网页沿原接口提交可见分镜文本，服务在受理时解析本次标签并沿任务记录关联分析。request.dataList 的 submittedContent（存在时）保留用户提交原串，content 是实际台词，directing 是从本次文本重新计算的内部信息；网页不维护这些字段。以当前镜头集合、顺序、台词和标签为准，不从旧分析恢复删镜、旧句或被删标签。analysisInput 是原始两栏，analysis.context 是初次采用说明；已采用的替换指令不重复执行。otherRequirements 沿任务记录传入，持续要求补充未指定部分；明确矛盾时报具体分镜，不暗改请求。没有指定人物时沿模板安排，不按问句猜已指定人物。

指定 speechTurns 按人物边界拆现有自然句段，保留 turnId，segmentId 继续作为 utterance.id；不跨人物、不按问号猜角色。visualDirections 与 chapter 交视觉作者，绝不拼入 TTS。kind=visual 只用明确画面与 durationSec 推进，不能从配音失败推断无口播。
