# visual-treatment-planning

读取 [视觉制作](../production-coordinator/references/visual.md)。先依当前全文与模板约束定义有限的版式、色彩语义、字体层级和材质原则，再制作代表性画面实际观察。不要仅交形容词或配色表。

先确定主要关系占据的空间，再安排标题、标签、字幕与固定包装；长中文按真实文字宽度和行高核对，不靠减小字号无限塞入。颜色必须区分对象或状态，保持跨场语义；低对比文字、细线和高频背景会降低可读性。图形角色、模板头像与正文各有层级，强调时避免抢同一焦点。

代表画面覆盖长文本、复杂关系、图形中间态和章节切口；查看真实渲染结果，修正重叠、失衡与误导后再扩展整片。新建运动关系按需读 motion-brief-writing，复杂层级按需读 depth-composition。
