# 财经双人模板生产说明

此包定义本栏目的文字解释、人物、固定包装及制作步骤，原稿及确认正文来自本次任务输入。完整读取动效组件与内容适配说明、renderer/src/types.ts、validateTimeline.ts、VisualBlocks.tsx、visualExtensions.tsx、FinancialDialogue.tsx。

本模板固定为 1920×1080、30fps。保留男女头像、Logo、SpeakerStage、栏目背景、中央面板外壳、导航、全片进度及字幕区。人物标签【财小策】和【室长】分别对应 speakerBindings 的同名键，绑定 female-host / finance.female 和 male-chief / finance.male；制作时按服务从当前标签计算的 speechTurns 采用，未指定发言按语义由男女两位承担，允许一人连续多句，不机械逐句轮换，不添加新对白。voiceRef 为 finance.female 与 finance.male，实际音色由服务器配置。

中央图解由本期作者在 src/visualExtensions.tsx 注册并实现；可以增加独立源码文件。保留正文原文、顺序、数字及原意，分镜内部按自然句段配音、实测时长；字幕按真实句段，拼接应完全等于确认正文。本文不提供本期章节数量或固定动效菜单。

全部音频及素材放 renderer/public。所有 src 都从 public 起，模板播放器和装配工具读取同一个地址，不自动补目录。例如 template-assets/assets/images/brand/logo-dark.png、template-assets/assets/audio/bgm/immersed.mp3；新配音由 assemble_sentence_audio 复制到 public/speech/ 并绑定为 speech/...。不复制素材到另一条地址适配旧播放器，不引用机器个人目录。保留原 BGM，按发言压低音乐；音效依据落点适量安排。

片头使用 template-assets/assets/video/intro 中原件，在开场钩子之后或正文之前安排；intro.frames 必须按原件实测，intro.fromFrame 为镜内起点，不能与 scene.chapter 重叠。片头结束后恢复原全局时刻的正文，不能重置图解或字幕时间；不得截断或遮蔽已确认口播。片尾使用 template-assets/assets/video/outro 中原件，在全部口播结束后完整播放一次。ending.narrationEndFrame 为片尾开始全局帧；ending.outro.frames 来自原件实测；totalFrames 包含片尾。源码已把片尾纳入 FinanceEpisode，不再用占位视频后替换流程；没有结束语授权不加稿。

镜头声音窗口直接由 scene.frames 与独立片尾起点计算，不填写已删除的 contentFrames。固定结束语只列 closingUtteranceIds，结束语之前最后正文句的实际末帧由播放器与校验器共同派生，不填写已删除的 ending.holdFrame；没有固定结束语就不保持。整章或整镜持续的图解省略 endFrameExclusive，播放器按所属章节或镜头当前末尾计算；明确的提前退出、itemFrames、revealFrame 仍是作者设定的真实局部帧，不随时长自动缩放。配音装配更新实测范围后，原视觉作者核对这些语义动作点，不重抄整章结束帧。

图解文字可使用 src/safe-visuals.tsx 中 DiagramText，明确取消 SVG 继承描边；动态数字可使用 RightAlignedValue，并按最长值预留空间。模板标题与数值卡已接入 PanelTitle/MetricCard，保留原布局并沿 LayoutGuard 检查实际尺寸。图解内部状态接管可用 VisualState，明确所属场面的 frame、fromFrame、toFrame；到止帧旧标题和图表一起卸载，跨场持续对象仍放共同父层，不重置全局时钟。字幕保留作者显式换行。每个自由场面独立源码，稳定包装只在确有共同问题时修改。这些组件不能代替实际布局与过渡观察。

公司名仅按当前采用台词或章节标题确定，写 intro.companyName 与 companyEvidence={sceneId,field:'content'或'chapter',start,end}；多家公司主次不明或没有公司为 null，换题后重新核对。CompanyTitleOverlay 在原片头标题下方叠字，空值无占位。每条 utterance 保存 speaker、turnId、voiceRef，人物按真实句段范围切换，停顿沿用 scene.speaker。明确无口播场景 directing.kind=visual、正文为空、有 visualDirections 和 durationSec，无需伪造 utterances/captions；片尾使用独立范围，scenes 的结束等于 ending.narrationEndFrame。

本模板制作顺序：采用当前确认分镜及人物 → 按人物拆自然句段，请求配音并同步设计图解结构 → 按真实声音装配时间线与字幕 → 原视觉作者按实测句段校准图解内部动作 → 检查栏目包装及完整合成 → 导出整片及分镜。结构、配色与组件可在配音等待期间制作，不先复制估算的整章结束帧。人物在 speakerBindings 中查找，未标记发言按上下文安排。定稿前从 renderer 目录运行 `node scripts/verify-episode.mjs --input <本 run 的 input.json 绝对路径> --timeline timeline.json`，核对片头公司名是否确实来自当前确认台词或章节；错误按具体分镜修正后重查。此检查是本模板的制作步骤，不要求通用 Worker 理解公司名。

本期时间线数据只维护 renderer/timeline.json；src/timeline.ts 固定导入此 JSON，禁止内嵌第二份对象。图解实现仍由本期作者维护对应源码。保持模板时序和 LayoutGuard 检查，不删除校验来通过渲染。使用本插件预览和渲染工具，整片及分镜全部使用 FinanceEpisode，正式导出不传 ranges，服务从冻结时间线推导确认分镜的全局范围，不能用 FinanceScene-* 重置全片时间。正式交付 N+1 文件，整片在前。

依赖已由部署提供，任务期间不安装包。模板 Arial 等西文字体仅用于拉丁文字；中文使用包内 Noto Sans SC。技术探测与抽帧不等于完整连续视听，检查真实范围如实记录。保护外观、正文图解、头像、Logo、字幕、片头片尾及声音均需实际核查。

章节制作按 input.chapterWork 最多八位作者滚动并行。每位作者仅在分配的 src/chapters/chapter_NNN 目录维护画面组件、纯参数校验器与视觉块 JSON。主协调统一共享设计，并保存工作单元与实际 timeline.chapters 的对应关系。统一配音装配完成后再按实际范围校准；作者不得修改总时间线、共享组件或注册表。

作者停止写入后，主协调合并视觉块，只替换相应章节的 visualBlocks，保留已经装配的声音、字幕和全部时序。主协调在 visualValidators.ts 注册纯校验函数，在 visualExtensions.tsx 注册组件与同一校验函数。纯校验文件不得导入 React、Remotion 或章节画面组件；validateTimeline.ts 只依赖 visualValidators.ts，防止提前校验时意外加载 React。注册后执行模板校验与同版预览。
