# 财经双人模板文字分析合同

本模板只生成 Remotion 动画，固定为 1920×1080、30fps。输入口播稿是待保留的旁白正文，不构成人物实拍或口型生成入口。

保留实际采用台词的原字、顺序、标点、数字和英文，不增写对白。每镜返回唯一 id、可编辑 content、正数 dur、durationSource=estimated。两栏共同理解，必要的人物与导演信息放进现有 content 的可见标签：【财小策】、【室长】、【画面：说明】、【章节：标题】。每镜独立标明必要人物；纯画面写【无口播：3秒】【画面：说明】，时长大于零且不超过 3600 秒。标签不朗读，普通括号台词保留。采用、替换或参考说明写原有 context，不输出隐藏 directing、字符范围或来源台账。只有要求没有可采用内容时报告缺项。

模板有固定男女头像。人物标签【财小策】和【室长】分别对应 speakerBindings 的同名键，绑定 female-host / finance.female 和 male-chief / finance.male；制作时按服务从当前标签计算的 speechTurns 采用，未指定发言按语义由男女两位承担，允许一人连续多句，不机械逐句轮换，不为角色分配增写对白。正式制作音色为 finance.female 与 finance.male，由服务器绑定。本阶段保留角色要求，不生成音频或人物表演。

原稿标记解释由本模板负责：【财小策 提问】整理为【财小策】；【室长 应答】、【室长 讲解】、【室长 收尾】整理为【室长】，后续实际台词原样采用。【室长 亮相】（室长出镜）属于画面要求，整理为【画面：室长出镜】，不是配音正文。公司概况、费用端、现金流等段落标题按当前内容整理为【章节：标题】，不固定章节数量或顺序。【定位语】中的悬念数字画面和【片头】中的栏目语结合本次文本及固定片头素材理解；画面说明不朗读，明确写出的栏目语不因包装重复而擅自删掉。不要把普通台词括号一律当导演说明。

人物身份、头像及音色是本模板固定配置；本期公司、数字、台词、角色发言顺序与画面要求来自本次任务。仅填写需求描述也应按内容理解，分析稿仍须经过网页确认后制作，不把输入位置当作成品稿状态。出现模板未声明的人物时报告人物与模板不匹配，不改配已有角色或增造绑定。

固定栏目 Logo、背景、导航、字幕区、片头片尾在制作阶段保留；这些包装不授权增写正文。片头不得截断已确认口播，片尾在全部口播结束后播放一次，无结束语授权不加稿。

业务分镜不等于动画章节或 TTS 句段。context 记录上述有效文字约束、拆分依据、未确定事项及本合同引用，不复制制作技术说明；本阶段无需读取组件源码、素材或制作方法。
